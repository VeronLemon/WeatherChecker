# WeatherChecker

Разработайте программу для поиска и проверки погодных данных с помощью регулярных выражений.

Программа позволяет находить в тексте, файле или на веб-странице:
- Температуру воздуха.
- Погодные условия: ясно, облачно, малооблачно, пасмурно, дождь, снег, дождь со снегом и их разновидности.
- Дни прогноза: сегодня, завтра, дни недели и их сокращения.

Найденные данные выводятся в формате:

`День | Температура | Погода`

Строки, в которых не указан день прогноза или температура, не выводятся.

## Структура проекта

- **main** — запуск программы.
- **application** — основная логика работы и поиск данных с помощью регулярных выражений.
- **domain** — класс погодных данных и интерфейс репозитория.
- **infrastructure** — получение текста из файла или с веб-страницы.
- **presentation** — консольное меню и вывод результатов поиска.
